Generator code from https://web.archive.org/web/20180611172721/https://hjemmesider.diku.dk/~pisinger/codes.html, specifically https://web.archive.org/web/20200703130800/http://hjemmesider.diku.dk/~pisinger/test3dbpp.c.

For the 3D-BPP, we used the 320 instances generated by
[Martello et al., 2000]. This set of instances consists of 8
classes, and each class is further divided into 4 groups. Every
group consists of 10 instances with same number of items; the
number of items per instance in the 4 groups are 50, 100, 150
and 200, respectively.

## Generate the 320 instances

Run `python generate_320.py` from this directory. The script writes 320
deterministic files under `instances_320/`: classes 1-8, item counts 50,
100, 150, and 200, with 10 instances for each combination. Use
`--output PATH` to choose another output directory.

Each file starts with `n W H D` and then has `n` lines of `w h d`.
Classes 1-5 and 8 use bins of size 100 x 100 x 100; class 6 uses
10 x 10 x 10; class 7 uses 40 x 40 x 40. Items have fixed orientation.

`generate_320.py` ports the generation logic and 32-bit random number
arithmetic from `test3dbpp.c`. The original C program also calls an
external solver and writes only solution statistics, so it cannot export
the item dimensions by itself.
