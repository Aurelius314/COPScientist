TSPLIB EUC_2D data from https://comopt.ifi.uni-heidelberg.de/software/TSPLIB95/tsp/tspindex.html

The 78 EUC_2D instances are in `tsplib_euc_2d/` as original `.tsp.gz` files.
Their proven optimal tour lengths are in `tsplib_euc_2d/optimal_values.json`,
keyed by instance name (the filename without `.tsp.gz`). These lengths come
from https://comopt.ifi.uni-heidelberg.de/software/TSPLIB95/tsp/TSP-BEST.html.
The compressed TSPLIB instance files are left unchanged.
